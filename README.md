# TYM

Premium landing page foundation for Yovani — real estate investor, advisor, and dealmaker.

## Direction

- Editorial, high-trust visual language with ink, acid-lime, and warm paper tones.
- Positioning focused on range: advisory, flips/new builds, creative deals, and tax-sale consulting.
- Single conversion goal: start a conversation around the visitor's opportunity.

## Run locally

Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Before launch

Replace the proof points and copy with verified claims, add Yovani's preferred contact destination, and add project photography/testimonials when available.
